### Diagnósticos preservados

- La primera prueba de navegador usó 127.0.0.1 y quedó sin hidratación: Next instalado bloquea por defecto ese Origin en recursos dev cuando inicia sin hostname. Se corrigió solo el arnés a `localhost`, sin ampliar configuración productiva ni permisos.
- Una expectativa de prueba intentaba leer `resumen_comprobantes_pago` como tabla; se corrigió a la RPC vigente `consultar_registro_comprobantes` de EPT-110. No fue un defecto de producto.
- Ejecutar en paralelo la matriz de permisos y la limpieza de UI produjo un deadlock entre DDL de fixtures (`ALTER/DROP TRIGGER`), no entre decisiones económicas. Se conservó el fallo, se restableció exclusivamente el stack propio desde cero y se serializaron las suites. El arnés conserva el error original y errores de limpieza, sin ocultarlos con un `finally`.
- El gate bash del selector debe acreditarse en Linux CI. No se modifica una negativa ni un gate para conseguir verde local.
