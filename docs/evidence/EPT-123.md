## Acceso iOS con Expo Go

Desde `mobile/`, con las tres variables `EXPO_PUBLIC_*` de producción exportadas:

```
npx expo start --tunnel
```

y escanear el QR con la app Expo Go del iPhone. El código es el mismo que el del APK. Limitación: Expo Go no aplica el
plugin de configuración de red `with-auth-integration-network-security`, que solo afecta a pruebas locales.
