# Recursos locales y licencias

Todos los recursos del render están dentro de este directorio. El render no usa red: cualquier solicitud que no sea `file:` aborta la ejecución.

| Recurso | Origen | Licencia |
|---|---|---|
| Outfit 400/500/600/700 (subconjunto latino, woff2) | paquete npm `@fontsource/outfit` 5.2.8 | SIL Open Font License 1.1 (texto en `fuentes-tipograficas/LICENCIA-Outfit-OFL-1.1.txt`) |
| Geist Mono (subconjunto latino, woff2) | copia incluida en `node_modules/next` (fuente de Vercel) | SIL Open Font License 1.1 |
| `imagenes/logo-emblema.png` | `public/logo-emblema.png` de este repositorio | Identidad institucional de Educar para Transformar |

El emblema institucional se usa sin alterar tal como figura en `public/logo-emblema.png`; su rótulo gráfico incluye la grafía «Trasformar», que no se corrige porque es el archivo oficial del repositorio.

Los íconos son SVG de trazo propio, definidos en `pantallas.mjs`. Los nombres de personas, importes y fechas son ficticios.
